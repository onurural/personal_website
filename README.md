# onurural.com

Personal site. A single static HTML file with inline CSS, no build step and no
JavaScript. GitHub Pages serves the root of `main` directly, so pushing to
`main` publishes.

```
index.html   the whole page, CSS inline
404.html     redirects unknown paths to the root
resume.pdf   CV
fonts/       JetBrains Mono (variable, latin subset, self-hosted)
CNAME        onurural.com
```
